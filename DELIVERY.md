# Передача Заказчику (пп. XIV, XV ТЗ)

Документ описывает состав передаваемого и соответствие технической спецификации.

---

## Что передаётся (п. XV ТЗ)

| Пункт ТЗ | Как выполнено |
|---|---|
| Исходный код | Весь монорепозиторий: `apps/`, `packages/`, `infra/` |
| База данных | Схема `apps/backend/prisma/schema.prisma` + дамп через сервис `backup` |
| Логины/пароли администратора | Создаётся сидом, меняется при первом входе |
| Доступы к хостингу, домену, сервисам | Передаются отдельным защищённым каналом |
| Отсутствие вендор-лока | Свои CMS и админка, открытые лицензии, никаких платных компонентов |

Шрифты Manrope и Inter — лицензия SIL OFL, свободны к использованию и передаче.

---

## Соответствие ТЗ по разделам

| Раздел ТЗ | Реализация |
|---|---|
| II. Технологическая платформа | Собственная CMS на NestJS, не конструктор и не готовый шаблон. REST API документирован в Swagger (`/api/docs`) |
| III. Мультиязычность | kk/ru/en, отдельные переводы, независимое редактирование, свой SEO и URL на язык |
| IV. Структура | 24 маршрута, меню-дерево в БД, редактируется без разработчика |
| V. CMS и роли | Роли Администратор/Редактор, `RolesGuard` на сервере |
| VI. Функциональные требования | Поиск (PostgreSQL FTS), адаптивность, версия для слабовидящих, карты, расширяемость |
| VII. Дизайн | Дизайн-система, адаптив, кроссбраузерность |
| VIII. Производительность | SSR/ISR, WebP/AVIF, кэш Redis, минификация, оптимизация запросов; постер-LCP на главной |
| IX. SEO и аналитика | sitemap.xml с hreflang, robots.txt, метатеги, подключение GA |
| X. Информационная безопасность | HTTPS, 2FA, argon2, brute-force защита, санитизация, CORS-allowlist, журнал действий |
| XI. Резервное копирование | Сервис `backup`: ежедневно, 30 дней, отдельное хранилище |
| XII. Техническое сопровождение | Health-check, логирование, документация |

## Этапы приёмки (п. XIV ТЗ)

## Развёртывание

Полная инструкция — в `README.md`. Кратко:

```bash
cp .env.example .env    # заполнить секреты
docker compose up -d --build
```

Наружу открыт только nginx. Миграции и первичная инициализация — автоматически.

## Что довести до продакшена

Честный перечень работ, оставшихся за рамками ядра и выполняемых на этапе 4
по установленным в проекте шаблонам:

1. **Админские экраны** для страниц, персон, документов, вакансий, галереи,
   ссылок, меню и настроек — по образцу готового модуля «Новости»
   (`apps/admin/src/pages/news/`). API для всех этих сущностей готов и
   документирован в Swagger.
2. **Публичные списковые страницы** вакансий, галереи и состава советов —
   по образцу готовых страниц новостей и документов (`apps/web`).
3. **Специализированные редакторы блоков** (визуальный редактор текста,
   выбор из медиабиблиотеки) поверх готового каркаса `BlockEditor`.
4. **Наполнение реальным контентом** Заказчика и **замер PageSpeed** на
   боевом хостинге с реальными изображениями.
5. **Выпуск TLS-сертификата** и настройка боевых доменов.

Архитектура, схема данных, безопасность, мультиязычность и весь публичный
слой API реализованы полностью.
